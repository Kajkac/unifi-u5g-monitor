# Changelog

## 0.1.0 — 2026-08-24

- Napravljena zasebna UniFi U5G aplikacija bez naslijeđenih modemskih integracija.
- Dodani SSH jump, UniFi managed credential discovery i strukturirani `mca-dump` status.
- Dodani SMS Inbox/Outbox, predlošci, automatizacije, Timeline i SQLite arhiva.
- Dodani signal/WAN/system dashboard, MQTT/Home Assistant i obavijesti.
- Dodani lokalna autentikacija, rate limiting, redaktirani backup i sigurna dijagnostika.
